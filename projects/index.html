Chest X-ray Pneumonia Classification with Explainable AI

Fine-tuned a ResNet18 model using PyTorch for pneumonia classification from chest X-ray images, achieving 81.89% accuracy through model training and evaluation.
Applied attribution-based XAI methods, including Grad-CAM, Integrated Gradients, and Occlusion, to visualize model predictions and analyze image regions contributing to classification decisions.
